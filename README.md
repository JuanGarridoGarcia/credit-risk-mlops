# credit-risk-mlops

Production system (MLOps) for a Lending Club credit risk model: PD, LGD and expected loss served through an API, with monitoring and retraining.

Work in progress. The research phase of this work lives in [A Deep Dive into Expected Loss](https://github.com/JuanGarridoGarcia/A-Deep-Dive-into-Expected-Loss-through-Credit-Scoring-Industry-Standard-Machine-Learning).

Designed by Juan Garrido García; implemented with AI agents.
